      Succès

      Comment ça marche ?
      • CPS : clicks par seconde.
      • Ton rang et tes succès se basent sur ta meilleure pointe : le plus de clicks réussis pendant une seule seconde, dans n’importe quel mode. Un test très court ne fausse donc pas le calcul.
      • Turbo, le dernier rang, demande 50 CPS : c’est presque impossible à la main.
      • Le compteur garde tous les clicks faits pendant les tests, même ceux d’un test arrêté.

      Records de ce mode

      Comment lire ces statistiques ?
      • Ces chiffres sont ceux du mode choisi : change d’onglet pour voir les autres.
      • Tests : les tests terminés (un test arrêté avant la fin ne compte pas).
      • Meilleur CPS et CPS moyen : ta vitesse sur toute la durée de chaque test.
      • Réussis : les clicks valables dans ce mode (sans les cibles ratées ni les erreurs d’alternance).
      • Dernier test : chaque barre montre ta vitesse pendant un petit morceau du test. La barre jaune est ton pic. Sur un long test, on voit bien la fatigue arriver !
      • Records : ton meilleur score pour chaque réglage. Clique sur une ligne pour remettre ce réglage.
      • Réinitialiser efface les statistiques et les records de tous les modes, mais garde ton rang, tes succès et ton compteur.
